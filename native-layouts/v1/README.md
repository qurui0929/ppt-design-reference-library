# 原生可编辑 PPT 案例库 v1.0

用于 `reference-driven-ppt`：匹配参考案例，直接创建原生 PPT，不经过生图。技能包仅含规则、脚本与固定版本索引，案例按需下载。

## 两条制作路径

- **T 类：原生样板复用。** 保留选中案例的原始构图与主题，替换原生文字，复杂插图与照片仍为独立图片。
- **N 类：原生配方重组。** 按内容关系重建可编辑文本、结构、表格和图表，支持统一换色。

已核验的是所列单页及示例，不代表所有原始资源已完成审美评估。参考案例与第三方模板不因此获得新的开源或商用许可；保留已有署名。

![项目实施流程](previews/N03.png)

![平台总体架构](previews/N05.png)

![项目组织与职责](previews/N06.png)

### N10 · 任务与阶段安排

### N11 · 方案对比与选择

对比维度一致；结论必须有依据，不能自动推荐。

### N12 · 任务优先级分析

![任务优先级分析](previews/N12.png)

二维分类，不把无数值的示意象限误称定量评分。

### N13 · 数据趋势与分析

![数据趋势与分析](previews/N13.png)

### N14 · 观点与支撑依据

![观点与支撑依据](previews/N14.png)

一个主观点与三段支撑，适合文字密度中等的说明页。

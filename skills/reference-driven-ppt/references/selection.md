# 案例选择

先选整套视觉家族，再匹配每页内容关系与容量。模板风格、色调、行业可以同时作为标签，不必把它们强行视作同一维度。源目录名称保留用户习惯。

组件库与综合灵感竞品都需检索。综合灵感中的逻辑图、架构图和其它排版是重要来源，不能只查看首页。文件名是初筛线索；解析所选案例的页内文字、导出相关页，实际查看后再定版。下载的完整PPT也可以贡献多个独立组件。

page-plan 至少记录页目的、业务内容、内容关系、候选文件ID与页码、已查看预览、最终选页、借鉴点和适配说明。保留构图、字体层次、留白、重心、图文比例、图片裁切与关系表达，不只借几个方框的拓扑。

内容真实性、关系正确及可读性是底线；在此基础上选择视觉成熟的案例。三段短观点与三段长文字不能只因数量相同就套同一布局。不能为套版式补造数字、照片或业务关系。

整套保持字体、色彩、标题体系一致，构图随内容变化。相邻页不要无理由重复同样等宽卡片，也不要为了变化随机混搭皮肤。目录收录不等于已审美评审；实际查看过的页才能标为 agent_viewed，用户确认后才是 user_approved。

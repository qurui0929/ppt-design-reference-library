# 原生制作

优先使用宿主的 Presentations 模板保留流程，阅读相应技能并定位当前运行时。v2收录的是原始PPT、PDF及图片等资料，不再提供旧N类几何配方；不能把原始文件目录传给旧配方作者器。

对选中的完整PPT先制作项目副本，检查母版、版式、文字、图表、表格、分组及图片。保持成熟构图，逐一替换案例事实。对表格、图表及结构关系用原生对象实现，复杂照片和插图独立保留。PDF和图片仅作参考，不能冒充原生模板。

需要从完整源PPT提取一页时，见 template-reuse.md。适配复杂富文本、图表或母版时，不应只做字符串替换；保留或重建相应原生对象。作者环境的正常验证要求继续适用；用户要求自行测试时不新增测试演示，不宣称已完成视觉验收。

封面、封底、过渡页可用生图强化背景或独立主视觉，调用当前环境可用的生图技能。优先无字画面，标题和业务内容仍用原生对象叠放。不得把这一例外扩展成所有内容页整页生图。

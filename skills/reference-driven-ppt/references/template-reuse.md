# 原始模板复用

v2中的文件是原始资料，不再预置T类单页映射。下载所选文件后，在项目副本中选择实际页码，保留母版、主题、字体及图片；原文件只读。

Windows PowerPoint提取页面时：以只读方式打开源文件，在内存中删除其余页面，另存新文件。不要将源页简单插到空白PPT后默认保存，这会改变主题色。不得保存覆盖原文件。

合并同画布页面可用 scripts/merge_native_pages.ps1；manifest 为 [{"path":"<absolute-pptx>","start":1,"end":1}]。脚本显式保留源页Design、ColorScheme与背景继承。合并后仍需将不同来源的标题、字体和颜色统一为本项目风格；不同画布先规范化，不能拉伸。

scripts/adapt_template.py 仅支持明确映射的单页原生文字替换，不会自动从完整PPT选页。只有先建立匹配该模板SHA-256、slide_part、text_slots的object_map后才适用。每个槽位包含slot、shape_id、suggested_max_chars；替换内容须显式覆盖所有旧文字。默认保留首段样式，复杂富文本需在作者工具中处理。一般优先使用宿主原生模板编辑能力。

源模板可能含照片、截图或栅格图表；先检查其实际对象类型，不承诺所有对象均可编辑。复杂业务图表需要重新建立原生数据。不能把整页导出图贴回去冒充原生复用。
